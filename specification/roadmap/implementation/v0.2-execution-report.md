## Detailed Results

### RF-006: The `LLMProvider` seam and its mock
**Status:** completed - **Commit:** `844b6dc` - **GitHub:** #6
**Validation:** [x] pytest 194 - [x] mypy strict - [x] ruff - [x] CI green - [x] contract test

`stream()` returns an `AsyncIterator[str]` and is **not** a coroutine function, so the caller can
await the *first* delta under its own budget rather than awaiting the whole call. The contract test
checks this by consuming a stream, not by reading annotations -- `get_type_hints` would happily
agree with an implementation that collected the reply and yielded it once.

The mock ships with the seam and carries the three levers the rest of the phase tests through:
several deltas, a *positioned* delay, and failure at a chosen index.

### RF-008: `orchestrator.py` -- the streaming turn and the first-token budget
**Status:** completed - **Commit:** `6677494` - **GitHub:** #8
**Validation:** [x] pytest 236 - [x] mypy strict - [x] ruff - [x] CI green - [x] contract test

The phase's centre. The `Responder` seam changed shape in shipped code, and the `reply` frame's
**cardinality** changed with it: N deltas with `final: false`, one terminal `final: true`.

The test that carries this asserts **interleaving, not frame count** -- it stalls the provider
before its fourth delta and requires the first three to have arrived already. It was **verified by
deliberately breaking it**: a router patched to collect all deltas and then send the same five
frames fails that test and passes every other test in the suite. A counting test would not have
noticed.

Also caught here: `Orchestrator` held per-session history in a dict nothing pruned. `forget()`
became part of the `Responder` seam and the router calls it at teardown -- the router owns the
connection's lifetime, so it owns the moment state is released.

### RF-009: Failure and abort semantics, and the `bad_frame` error code
**Status:** completed - **Commit:** `64607c0` - **GitHub:** #9
**Validation:** [x] pytest 267 - [x] mypy strict - [x] ruff - [x] CI green - [x] contract test

**Architecture impact.** `ErrorCode` grew to **twelve** values. `bad_frame` and `internal` split by
whose fault it is: the device sent something unparseable, versus the server broke. All three codec
exceptions and all five router rejections moved off `internal`. This closes v0.1 code-review
finding 9, decided by the user on 2026-08-23.

History rollback removes the failed turn's user message **by identity, not position** -- "the last
message" would be wrong the moment two turns interleave on a session, and would silently delete a
healthy turn's question. The one case that ends without a reply and keeps its message is a silent
model: the person did speak.

The contract test caught the enum change by itself, which is what a pinned seam is for.

## The DoD, verified against the real API

Roadmap §v0.2: *"a `text_in` from the fake device returns a real Gemini answer **arriving as a
stream of deltas, first delta well before the reply is complete**, with the first-token budget
enforced; every provider failure surfaces as an enumerated `error` and leaves history consistent;
no test makes a paid call."*

Run end to end through the fake device against the live API:

deltas   : 3 reply frames

Ukrainian and one sentence, so RF-007's language and brevity instructions both landed.

## What the live run caught that no mock could

The SDK printed an **automatic-function-calling recommendation to stderr on every turn**. We pass
no tools, so AFC is now disabled explicitly. A production log filling with advice about an unused
feature is precisely the class of defect a fully mocked suite cannot see -- which is the argument
for the DoD's manual check being performed rather than merely documented.

## Architecture impact -- for the next reconcile

1. **`ErrorCode` has twelve values** (RF-009). `bad_frame` is the device's fault, `internal` the
   server's. ARCHITECTURE §Error codes carries the rule; v0.3's firmware must render both.
2. **The `Responder` seam is a stream** (RF-008): `respond(session_id, text) -> AsyncIterator[str]`,
   with `forget(session_id)` called at teardown. Any later responder implements both.
3. **`reply` cardinality changed** (RF-008): a turn is N deltas plus one terminal frame. The frame
   itself is unchanged, so v0.3's firmware parser needs no new branch -- but it must not assume
   one reply per turn.
4. **`create_app` takes `settings`** (RF-011) and builds the real provider only when given them.
