## Detailed Results

### RF-023: `pure/transcript.h`
**Status:** completed · **Commit:** 58b46b0
**Validation:** [x] `pio test -e native` (121) · [x] `pio run -e cores3` · [x] acceptance

Codepoint-based wrapping and a transcript that accumulates a streamed reply. The two decisions that
matter: columns are characters (Ukrainian is two bytes per letter, so a byte-based wrap fits half as
many and cuts letters in half at the break), and an incomplete trailing UTF-8 sequence is held back
until the frame that completes it (the server streams bytes, so a letter can straddle two frames).

22 host tests. The strongest is the equivalence: splitting a reply at **every** byte offset --
guaranteeing some splits land inside a two-byte letter -- produces the same lines as appending it
whole.

### RF-024: A Cyrillic font for the panel
**Status:** completed · **Commit:** 8b1a285
**Validation:** [x] `pio test -e native` (125) · [x] `pio run -e cores3` · [x] acceptance

-Misc-Fixed 10x20, public domain, via `lgfx::U8g2font`. Coverage was **verified by decoding the
array's own glyph table**, not assumed from the name: 387 glyphs, ASCII plus U+0400..U+0523. The
decode is corroborated by reaching exactly the 387 the file itself declares.

**A host test caught a false claim during this issue.** The first version asserted that 264/10 and
184/20 divide exactly; they do not, and the comments in `layout.h` and the font source said they
did. The grid uses 260x180 of 264x184. Both comments were corrected and the test now pins what is
true: the grid is the largest that fits.

## Architecture impact

**None.** No seam changed: the WS protocol, `EmotionFrame`, the provider seams, `IFaceRenderer` and
the capability flags are all as v0.4 released them. The console changes what is *shown*, not what is
*sent*, and draws into the sprite the renderer already owned.

Two internal facts the next version should build on rather than rediscover:

- **`pure/layout.h` now carries the console grid** (`kConsoleAdvanceWidth/LineHeight/Columns/Lines`),
  and both the wrap and the renderer read it. A later font change must update those numbers; the host
  test fails if the grid stops being the largest that fits.
- **The loop's push path redraws the console as well as chrome.** Anything else that later draws into
  the sprite outside `render()` must be added there too, or it will be marked dirty and never
  repainted.

## Known gap carried forward

The font covers ASCII and U+0400..U+0523. **General Punctuation is outside that** -- en dash, em dash
and the typographic apostrophe all draw as nothing. The first long Ukrainian reply of the DoD check
contained two of them, so this is real rather than theoretical. Words are unaffected, which is why
the DoD passes. Recorded in the font source, `TESTING.md` and `DEPLOYMENT.md`.
