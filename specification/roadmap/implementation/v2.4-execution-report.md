## Three findings that were not in any issue

**A collision in the specification, found by encoding one frame.** ARCHITECTURE §event{} showed
`{"type": "touch", "kind": …}` — but the envelope's `type` names the *message*, a rule every frame
follows and `decode_envelope` depends on. Spreading the event's fields into it produced a frame the
server decoded as an unknown message called `touch`. The example had been describing the inner
object rather than the frame. Nested under `event` now, with the reason recorded in the document.

**A test that found a defect in itself.** `(t / 20) % 7 - 3` with `t` unsigned underflows to four
billion for three samples in every seven, so the IMU's noise fixture fed the detector garbage and it
reported 47 shakes. The same unsigned subtraction cost this project hours in v1.4, where a listening
window closed after 53 ms. Writing it a second time is why that fixture now carries a note and not
just a cast.

**A limitation, asserted rather than wished away.** The router's receive loop is serial, so an event
arriving mid-reply is handled when the turn ends rather than during it. The first version of that
test asserted the face changed during the turn, and failed correctly. It is acceptable precisely
because the model has two levels: the reflex already fired on the device, milliseconds after the
finger landed and without consulting anyone. What arrives late is the character's comment, and a
comment is allowed to be late. Concurrency during a turn is v3.4's — the test will notice when it
lands.

## What this phase inherited and did not break

Three rules earned in v2.1–v2.3, each of which a reflex layer was positioned to break:

- **The face may drop frames; the microphone may not.** Untouched — the reflex adds no frames of its
  own, it modulates the ones already being drawn.
- **A reflex must not touch the mouth while the device speaks.** Implemented and tested for every
  reflex over every emotion.
- **Anything that feeds an animation must answer: what happens when it stops being updated?** A
  reflex is by definition a thing that stops, so this is its first test — and the affection that
  builds across taps fades for the same reason.
