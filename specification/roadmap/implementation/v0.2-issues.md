# v0.2 — GitHub Issues

Issues for phase **v0.2 — Gemini and the orchestrator** (version **v0 — Skeleton**),
derived from the per-phase Tasks in [ROADMAP.md](../../ROADMAP.md) (§v0.2) and the
contracts in [ARCHITECTURE.md](../../ARCHITECTURE.md) (§Components, §Contracts → WS device↔server,
§Error codes, §Turn lifecycle → Streaming is the architecture / Budgets and abort semantics,
§Model policy — Gemini only, §Providers and seams, §Configuration and secrets, §Testing and CI).
This file is scoped to a single phase; IDs continue from the previous phase
(RF-005 → **RF-006…RF-011**).

v0.2 turns the echo into a conversation. It adds the **`LLMProvider` seam** and its single real
implementation — Gemini 2.5 Flash with `thinkingBudget: 0` — plus the **orchestrator** that runs a
turn and streams it. The load-bearing property is not "an answer arrives" but *how* it arrives:
every token delta leaves as its own `reply` frame the moment it exists, because v1's TTS starts
synthesizing on the first completed phrase and cannot do that if the reply is accumulated first.
Getting this shape right now is what makes the whole voice loop possible later; getting it wrong
would be discovered in v1 with a rewrite as the fix.

## v0.2 — Gemini and the orchestrator

### RF-006 — The `LLMProvider` seam and its mock

**Description:**
The third of the five seams (ARCHITECTURE §Providers and seams). A new `server/roboface_server/providers/`
package holding `base.py` — the `LLMProvider` Protocol and `ProviderError` — and `mock.py`, the
deterministic implementation **every test uses by default**. Nothing here calls a network.

The seam and its mock ship together on purpose: a provider Protocol with no test double is a
contract nobody can build against, and RF-008 is written entirely against this mock.

**What needs to be done:**
- `providers/base.py`:
  - `LLMProvider` as a `Protocol` with `def stream(self, system: str, messages: Sequence[Message]) -> AsyncIterator[str]`
    — an **async iterator of text deltas**, per ROADMAP §v0.2. Not `async def … -> str`: the return
    type *is* the streaming guarantee, and a signature that can return a whole reply will eventually
    be handed one.
  - `Message` — the role/text pair the orchestrator keeps a turn's history in (`role: "user" | "model"`,
    `text: str`). A frozen dataclass; **not persisted** — SQLite is v4 (ARCHITECTURE §Data model).
  - `ProviderError(Exception)` carrying an **optional** `ErrorCode` hint, so an adapter that knows it
    was rate-limited can say so and one that only knows it failed does not have to guess.
- `providers/mock.py`:
  - A `MockLLMProvider` yielding a canned, **deterministic** delta sequence — configurable per
    instance (the deltas to yield, an optional per-delta delay, an optional exception to raise at a
    chosen index). RF-008 and RF-009 need all three to test streaming, timeouts and mid-stream
    failure without a network.
  - Deltas are **word-or-fragment sized, and there are several** — a mock that yields one string is a
    mock that lets a non-streaming implementation pass.
- `providers/__init__.py` exporting the seam.
- ARCHITECTURE §Providers and seams already names this seam; **update it only if the signature
  written here differs from what it describes**, and then in this issue.

**Dependencies:** None — this is the phase gate.

**Expected result:**
An importable seam with a deterministic mock behind it, so every later issue in this phase can be
built and tested with no API key present.

**Acceptance criteria:**
- [ ] **Contract test** (`tests/contract/test_llm_provider.py`) pins the seam: `stream` is an async
      iterator (asserted by *consuming* it, not by reading annotations), its `(system, messages)`
      shape, `Message`'s fields, and that `ProviderError`'s code hint is optional. Any divergence from
      ARCHITECTURE §Providers and seams updates that document in this same issue.
- [ ] `MockLLMProvider` yields **more than one** delta for a normal reply, and the same deltas every
      time it is run — determinism is what makes the suite trustworthy.
- [ ] **Unit test:** the mock's failure injection raises at the configured delta index, and its delay
      option is honoured, so RF-008/RF-009 have the levers they need.
- [ ] No module in `providers/` imports a network client at import time; `mock.py` never does at all.

### RF-007 — `prompt.py` — minimal system-prompt assembly

**Description:**
`server/roboface_server/prompt.py`: a pure function that assembles the system prompt a turn is run
with. **Deliberately minimal** — a placeholder character until v4.1 brings the canon file
(ARCHITECTURE §The mind). Pure and dependency-free, like `protocol.py`, so it is testable as a string
transformation and cannot acquire hidden inputs.

**What needs to be done:**
- `build_system_prompt(...) -> str` assembling: who RoboFace is (a short placeholder persona), the
  language expectation (Ukrainian is the product's language — MISSION), and the brevity instruction
  that matters for a spoken character (a reply is *heard*, not read; long paragraphs are a latency
  cost paid by the listener).
- A named constant for the placeholder persona, marked with the version that replaces it (**v4.1**,
  `ROBOFACE_CANON_PATH`), so it is obvious this is a stub and not a design.
- Keep it a **pure function of its arguments** — no file reads, no config, no clock. v4.1 will pass
  the canon in; it must not have to unpick a hidden dependency first.

**Dependencies:** None — runs in parallel with RF-006.

**Expected result:**
One function returning a stable system prompt string, with no I/O.

**Acceptance criteria:**
- [ ] **Unit test:** prompt assembly is deterministic, includes the persona and the brevity and
      language instructions, and is a pure function — the same arguments give the same string, and no
      file or environment variable is read (asserted, not asserted-by-inspection).
- [ ] The placeholder is explicitly marked as superseded by v4.1, so a later reader does not mistake
      the stub for the intended character.

### RF-008 — `orchestrator.py` — the streaming turn and the first-token budget

**Description:**
The heart of the phase. `server/roboface_server/orchestrator.py` runs a text turn and **streams it**:
each delta from the provider leaves as its own `reply{text, final: false}` frame the moment it
arrives, followed by a terminal `reply{final: true}`. It also **replaces the `Responder` seam**
in the released `router.py` (see reconciliation R1/R2) — this issue edits shipped code.

ARCHITECTURE §Streaming is the architecture, not an optimisation is the specification here: *"the
reply is never accumulated and sent whole"*. The observable consequence is what the test asserts.

**What needs to be done:**
- **Change the `Responder` seam** in `router.py` from `async def respond(self, text: str) -> str` to
  a streaming shape (an async iterator of deltas). Update `EchoResponder` to match — it stays, as the
  router's own test double, and now yields its echo in **more than one** delta so the router's
  streaming path is exercised without an orchestrator.
- **Rewrite the `text_in` branch** (`router.py:258-262`): consume the stream, `await transport.send`
  each delta as its own `Reply(final=False)`, then one `Reply(text="", final=True)` to close the turn.
  Do **not** buffer.
- `orchestrator.py`:
  - `Orchestrator` implementing the new `Responder` shape, holding an `LLMProvider` and the system
    prompt from RF-007.
  - **Per-session history**, in memory, keyed by `session_id` (ARCHITECTURE §Data model: nothing is
    persisted before v4). The user message is appended before the call; the model's reply is appended
    on success. RF-009 adds the rollback on failure.
  - **The first-token budget (~8 s), awaited on the first `__anext__()` only** — ARCHITECTURE §Budgets
    and abort semantics: *"awaited on the stage's first output so a stalled provider fails fast while
    a slow-but-flowing one is never cut off mid-reply"*. A single timeout around the whole stream
    would truncate a long, healthy answer; that distinction is the requirement.
  - The budget is a module constant, **injectable** so tests need no real waiting.
  - Log the turn through `roboface_server.logging` — `chars`, never bodies (the released module's
    rule).
- Keep the router free of provider knowledge: it consumes an iterator and knows nothing about Gemini.

**Dependencies:** RF-006, RF-007

**Expected result:**
A `text_in` produces a stream of `reply` deltas against the mock provider, with the first delta sent
before the last is generated, and a stalled provider failing fast on the first-token budget.

**Acceptance criteria:**
- [ ] **Contract test:** the **`reply` delta shape** — a turn produces **many** `reply` frames, all
      but the last with `final: false`, exactly one terminal `final: true`. This pins the streaming
      contract against a future change that quietly re-accumulates.
- [ ] **Integration test (the DoD's core):** a `text_in` from the fake device yields **multiple**
      `reply` frames from the mock, read with `drain`. Assert **interleaving, not just count** — a
      delta is received while the provider still has deltas to give, which is the property a buffered
      implementation fails and a counting-only test would miss.
- [ ] **Unit test:** the first-token budget fires when the mock stalls before its first delta, and
      does **not** fire when the mock is slow *between* deltas — both directions, with the LLM mocked
      and no real waiting.
- [ ] **Unit test:** history accumulates user and model messages per `session_id`, and two sessions do
      not share one.
- [ ] The router still passes its full v0.1 suite: `ping`/`pong`, teardown on all three paths, and the
      `proto_unsupported` rejection are unaffected by the seam change.

### RF-009 — Failure and abort semantics, and the `bad_frame` error code

**Description:**
Everything that happens when a turn does not go well. Maps provider failures to enumerated codes,
rolls a failed turn's user message back out of history, and — per the user's decision on **code
review finding 9** — adds **`bad_frame`** to `ErrorCode` so a device-side fault stops being reported
as a server-side one.

**What needs to be done:**
- **Error mapping** in the orchestrator: a `ProviderError` with a code hint uses it; without one it
  becomes `llm_failed`; a first-token budget breach becomes **`llm_timeout`**; a provider signalling
  quota becomes **`rate_limited`**. The device receives `error{code, msg}` and returns to idle; the
  session stays connected (ARCHITECTURE §Budgets and abort semantics).
- **History rollback:** an aborted turn removes the user message it appended, so the next turn starts
  consistent. ARCHITECTURE is explicit — *"rolls the user message back out of history"* — and the
  failure it prevents is a model seeing a question it never answered.
- **A mid-stream failure is not a silent truncation:** if the provider dies after some deltas, the
  device gets an `error` frame, not a `reply{final: true}` that would make a half-sentence look
  finished.
- **Add `bad_frame` to `ErrorCode`** (a seam change → ARCHITECTURE §Error codes + the contract test in
  **this** issue): `MalformedFrame`, `UnknownMessage` and `UnsupportedMessage` stop reporting
  `internal`. Remove `protocol.py`'s documented caveat about the gap at the same time — leaving it
  would read as an open question after it has been answered. `internal` keeps its real meaning: the
  server broke.
- Distinguish the empty case from the failure case: a provider that yields **no deltas at all** ends
  the turn cleanly (a `reply{final: true}` with no content), not with an error — the ARCHITECTURE
  precedent is *"silence that transcribes to nothing ends the turn cleanly … not an error"*.

**Dependencies:** RF-008

**Expected result:**
Every provider failure reaches the device as one enumerated `error` code, and history is consistent
afterwards whether the turn succeeded, timed out, or died halfway through.

**Acceptance criteria:**
- [ ] **Contract test:** `ErrorCode` now has **twelve** values including `bad_frame`; the ARCHITECTURE
      §Error codes list is updated in the same commit. The protocol contract test changes with it.
- [ ] **Unit test:** each failure maps to its code — hinted `ProviderError` → its hint, unhinted →
      `llm_failed`, first-token breach → `llm_timeout`, quota → `rate_limited`. LLM mocked.
- [ ] **Unit test:** history rollback — after a failed turn the user message is **gone**, and a
      following successful turn sees a consistent history. Asserted for a failure before the first
      delta *and* one part-way through the stream.
- [ ] **Integration test:** a mid-stream provider failure delivers `error{code}` to the fake device and
      **no** `reply{final: true}`; the connection stays open and a subsequent turn succeeds.
- [ ] **Unit test:** a zero-delta reply ends the turn cleanly rather than as an error.

### RF-010 — `providers/gemini.py` — the Gemini 2.5 Flash adapter

**Description:**
The seam's **one real implementation**. `providers/gemini.py` streams from Gemini 2.5 Flash with
`thinkingBudget: 0`. MISSION and ARCHITECTURE §Model policy are unambiguous: this is the only chat
vendor, and a second is a non-goal, not a backlog item.

Independent of RF-008 by construction — that is what the seam is for — so the two run in parallel.

**What needs to be done:**
- Add the Google GenAI SDK to `requirements.txt`. Import it **lazily or at module level only**, never
  in a way that makes `providers/__init__` require it — `mock.py` must keep working with the SDK
  absent, and the contract test must not need a key.
- `GeminiProvider` implementing `LLMProvider`: stream the model's deltas as they arrive and yield each
  one immediately. **Never** collect the response and yield it whole — that would satisfy the type and
  destroy the property.
- `thinkingBudget: 0` (lowest time-to-first-token — the documented reason it was chosen), the model id
  from configuration, safety settings set explicitly rather than left to a default that may change.
- Translate SDK exceptions into `ProviderError` **with a code hint where the SDK makes one knowable** —
  a quota/429 becomes `rate_limited`. The orchestrator must never see a vendor exception type;
  that is the seam's entire job.
- Read `GEMINI_API_KEY` from configuration (RF-011), never from a literal, and **never log it** — the
  released logging module's redaction rule applies.
- An **opt-in** live test (an env-gated marker, skipped by default) that makes one real call. It must
  be impossible to run accidentally: CI runs the default suite, and the default suite is free.

**Dependencies:** RF-006

**Expected result:**
A Gemini adapter that yields deltas as they arrive and raises only `ProviderError`, exercised in CI
without a key and verifiable by hand with one.

**Acceptance criteria:**
- [ ] **Unit test (SDK mocked, no network):** the adapter yields each delta as it arrives — asserted by
      driving a fake streaming response and checking deltas emerge **before** the fake is exhausted,
      not merely that they all arrive.
- [ ] **Unit test:** `thinkingBudget: 0` and the configured model id are actually passed to the SDK;
      SDK exceptions surface as `ProviderError`, with a quota error carrying the `rate_limited` hint.
- [ ] **No paid call in the default suite** — the live test is env-gated and skipped by default, and a
      test asserts it is skipped when the gate is unset, so the guard cannot rot.
- [ ] `GEMINI_API_KEY` appears in no log line and no error message (asserted, given the adapter
      formats exceptions).

### RF-011 — Gemini configuration and provider selection

**Description:**
The joining step that makes the DoD real: teach `config.py` the three Gemini variables and let
`create_app` build the orchestrator with the real provider — while every test keeps getting the mock.

**What needs to be done:**
- `config.py` gains **exactly** the three variables ARCHITECTURE §Configuration marks **v0.2**:

- `server/.env.example` already lists all three; verify against ARCHITECTURE and correct only on a
  genuine mismatch.

**Dependencies:** RF-008, RF-010

**Expected result:**
`python -m roboface_server.app` with a key in `server/.env` answers a `text_in` from a real device
with a real, streamed Gemini reply; the suite runs unchanged with no key present.

**Acceptance criteria:**
- [ ] **Unit test:** the three Gemini settings load with their defaults, are overridden by the

- [ ] **Integration test:** `create_app()` with an injected mock responder behaves exactly as it does

- [ ] **Manual DoD check (documented, not automated):** with a real key, a `text_in` returns a real

## v0.2 scope notes

**Total effort:** ~16 points (S=1, M=3, L=5) — roughly 2–3 developer-weeks; the orchestrator is the
single largest piece and the only `L`.
**Critical path:** RF-006 → RF-008 → RF-009, with RF-011 joining RF-010 in at the end.
RF-007 is free-standing; RF-010 runs alongside RF-008.
**Phase DoD (roadmap §v0.2):** a `text_in` from the fake device returns a real Gemini answer
**arriving as a stream of deltas, first delta well before the reply is complete**, with the
first-token budget enforced; every provider failure surfaces as an enumerated `error` and leaves
history consistent; no test makes a paid call.
**Contracts pinned this phase:**
- the **`LLMProvider` seam** — `tests/contract/test_llm_provider.py` (RF-006);
- the **`reply` delta shape** — a delta stream, not one final message (RF-008), pinned in the WS
  protocol contract test;
- the **`ErrorCode` enum grows to twelve** with `bad_frame` (RF-009) — ARCHITECTURE §Error codes and
  `tests/contract/test_ws_protocol.py` change in that same issue.
**Explicitly out of scope, by design:** no ASR, no TTS, no audio of any kind (v1); no firmware (v0.3);
no face (v0.4); no persistence — history is in memory and SQLite is v4; no canon file — the system
prompt is a marked placeholder until v4.1; no `google_search` grounding (v4.3); no second chat vendor,
ever.
**Model note:** chat runs on **Gemini 2.5 Flash only** (`thinkingBudget: 0`) behind the `LLMProvider`
seam; **no paid APIs** — every provider seam is mocked and a fake device drives the protocol for unit +
integration tests. The one live test is env-gated and skipped by default.
