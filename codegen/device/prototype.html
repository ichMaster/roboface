Core2 device screens — prototype

Six screens at true 320×240, drawn from the exact BLE frames defined in device-frontends-vision.md. Every number below is real, measured from run-20260815-213849 — 42 issues, 15 releases, 4.1 hours.

Nothing here is pseudographics: the arcs, curves and bars are true anti-aliased vector shapes, which is what LovyanGFX draws on the real panel. This file is a design reference — it is never served and never flashed.

Dark only — the palette is copied verbatim from the dark block of dashboard/static/styles.css, so the panel and the browser read as one product.

Frames these screens render from

The device asks; the bridge answers. {"want":N} goes out over Notify, the JSON comes back over Write. Two loops run independently: notifications every 5 s — the only channel that can buzz, and so the only real latency requirement — and the active screen every 15–120 s, paced by how fast that screen's own data actually changes. Every value arrives display-ready; the device computes nothing at all, and each answer carries next, telling it when to ask again.

Why this needs no font work

Every curve, ring, bar and dot on these screens is a shape, not a glyph. The frame carries "sp":"7511232" and "vs":"##############>" — digits and ASCII flags — and the firmware turns them into geometry. So the only glyphs the panel ever renders are [A-Za-z0-9 .:/%-], which the stock Latin font already covers. No Cyrillic set, no custom glyph range, and no box-of-question-marks surprise that only shows up on hardware.

Budget

A full-screen RGB565 sprite is 150 KB — 1.8% of the Core2's 8 MB PSRAM. A complete anti-aliased repaint costs roughly 110 ms against a 15,000 ms budget on the fastest screen — under 1%. The usual reason embedded UIs look crude, no time in the frame, does not apply at these rates.

There are no partial redraws, and that is not an optimisation we declined — it is what statelessness leaves. Dirty-region tracking needs a previous frame to compare against, and the device never keeps one. Every answer repaints the whole screen.
